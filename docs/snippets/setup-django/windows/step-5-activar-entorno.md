!!! info "5. Activar el entorno virtual"

    Ejecuta el siguiente comando para activar el entorno virtual:

    ```{ .powershell .cmd }
    .\.venv\Scripts\activate
    ```

    Una vez activado, deberías ver `(.venv)` al comienzo de la línea de comandos.

    ```{ .powershell .cmd .no-copy  hl_lines="1" }
    (.venv) C:\Users\mcherrera\nuevo-proyecto
    ```

    Ahora tenemos un entorno limpio y listo para trabajar.

!!! info "7. Generar un nuevo"

    Con la herramienta `django-admin` y el comando `startproject` se puede generar automáticamente la estructura inicial de un nuevo proyecto Django.

    ```powershell title="Terminal"
    (.venv) django-admin startproject _site .
    ```

    Utilizamos un punto `.` al final del comando para generar el proyecto en el **directorio actual**, evitando que Django cree una carpeta adicional con el nombre del proyecto.
